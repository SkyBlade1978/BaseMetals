# Supported versions

Base Metals `3.0.1.118021` targets Minecraft 1.18.2, Forge 40.3.0, and Java 17.
The build compiles and qualifies against the exact public OreSpawn
`4.0.16.118021` release (CurseForge project 245586, file 8780769), while the
published runtime contract remains OreSpawn `[4.0.1,5.0.0)` because provider
schema 3 is stable across the supported OreSpawn 4 line.

Release artifacts use Maven coordinate
`zone.moddev.mc.basemetals:BaseMetals:3.0.1.118021`.
